# 🎮 ROUTINE-CALENDAR.WEB (Myplan)

> **1989 Nintendo Game Boy(DMG-01) 스타일의 8-bit 레트로 루틴 & 습관 트래커 웹 애플리케이션**  
> 실제 시간(연도·월·주차·오늘)과 실시간 연동되며, Vercel 1클릭 배포에 완벽히 최적화되어 있습니다.

![Preview](https://raw.githubusercontent.com/udd43/Myplan/main/favicon.svg)

---

## 🌟 주요 특징

1. **오리지널 게임보이(DMG-01) 4-Shade 그린 모노크롬 감성**
   - 레트로 4색 팔레트 (`#9bbc0f`, `#8bac0f`, `#306230`, `#0f380f`)
   - 도트 매트릭스 LCD 화면 격자 질감 및 픽셀 테두리
   - 부팅 로고 낙하 애니메이션 및 시그니처 8비트 부팅 사운드
   - 깜빡이는 전원 LED 및 사운드 ON/OFF 스위치

2. **실제 날짜 및 실시간 주/월 자동 연동 (Real-time Calendar Sync)**
   - **현재 주차 자동 인식**: 오늘 날짜를 기준으로 해당 월의 주차(`Week 1` ~ `Week 5`)가 자동으로 활성화됩니다.
   - **다음 주 자동 전환**: 시간이 흘러 다음 주차가 되면 해당 주차로 자동 전환되며 이전 기록은 안전하게 보존됩니다.
   - **달력 요일 & 날짜 헤더**: 매월 1일의 요일부터 시작하여 7일 단위로 정렬되며, 헤더에 요일과 날짜(예: `목 10/8`, `토 10/10★`)가 표시됩니다.
   - **오늘(TODAY) 강조**: 오늘 날짜 열과 헤더에 별표(★)와 하이라이트가 적용됩니다.
   - **월 이동(◀ / ▶) 및 홈(🏠) 버튼**: 과거/미래 월을 자유롭게 탐색할 수 있으며, 홈 버튼 클릭 시 오늘 날짜의 주차로 즉시 복귀합니다.
   - **주소창 동적 연동**: 브라우저 주소창에 `ROUTINE-CALENDAR.WEB/2026/10/W2_` 형태로 현재 탐색 중인 연/월/주차가 실시간 표시됩니다.

3. **분석(ANALYSIS) & 통계**
   - **실시간 픽셀 도넛 차트**: Canvas 기반 44×44 픽셀 링 차트
   - **스코어보드**: 주간 목표, 실제 완료, 남은 개수 실시간 연산
   - **루틴별 진행률 바**: 업무, 러닝, 식단, 홈트, 금주, 6시 기상 20칸 세그먼트 게이지
   - **일일 진행률 막대 차트 (1~15일 / 16~말일)**: 해당 월의 일별 완료율을 2D 픽셀 막대로 시각화
   - **주요 루틴 TOP 5**: 월간 달성 횟수 기반 실시간 순위 및 1위 트로피(🏆) 수여

4. **홈트 상세 가이드 & 당일 추천 운동 (어깨 프레임 확장 1주일 루틴)**
   - 루틴의 **'홈트'**를 클릭하면 **15kg 덤벨 기반 어깨 프레임 확장 1주일 루틴** 모달이 열립니다.
   - **오늘의 당일 추천 운동**: 현재 요일을 실시간 인식하여 오늘의 맞춤형 운동(운동명, 세트/반복수, 수행 팁)을 상단에 즉시 추천합니다.
   - **요일별 상세 계획**: 월(어깨 볼륨/밀기), 화(등 프레임/당기기), 수(하체/휴식), 목(어깨 3D 측/후면), 금(등 볼륨/코어), 토(전신 펌핑), 일(완전 휴식).
   - **15kg 덤벨 점진적 과부하 팁**: 네거티브 집중, 휴식 시간 단축, 선피로 훈련법 제공.
   - **원클릭 완료 체크**: 모달 내에서 `⚡ 오늘 홈트 완료 체크하기!` 버튼 클릭 시 오늘 루틴이 즉시 체크 반영됩니다.

4. **8-bit 사운드 & 컨트롤러 조작**
   - Web Audio API 사각파(Square Wave) 칩튠 효과음 (체크음, 이동음, 부팅음, 탭 전환음)
   - 키보드 조작:
     - 방향키 (<kbd>←</kbd> <kbd>↑</kbd> <kbd>↓</kbd> <kbd>→</kbd>): 그리드 커서 이동
     - <kbd>Z</kbd> 또는 <kbd>Enter</kbd>: 체크 토글 (A 버튼)
     - <kbd>X</kbd>: 체크 해제 (B 버튼)
     - <kbd>Shift</kbd>: 다음 주차 전환 (SELECT)
     - <kbd>Enter</kbd>: 메뉴 열기 (START)
   - 모바일 & 터치스크린: 실물 형태의 십자키, A/B 버튼, SELECT/START 버튼 직접 터치 가능

5. **Vercel 최적화 & 로컬 영속성**
   - 순수 HTML5 / Vanilla CSS / JavaScript (의존성 없는 0ms 번들링, 초고속 엣지 서빙)
   - `localStorage`를 통해 브라우저를 닫거나 새로고침해도 모든 체크 기록 영구 보존
   - Vercel 보안 헤더, 캐싱 규칙 (`vercel.json`), SVG 파비콘 완비

## 🚀 Vercel 배포 방법

이 저장소는 Vercel에 즉시 배포할 수 있도록 설정되어 있습니다.

1. [Vercel 대시보드](https://vercel.com/new)에 접속합니다.
2. GitHub 저장소 `udd43/Myplan`을 선택하고 **Import**합니다.
3. 빌드 설정(Build Settings)은 기본값(정적 사이트) 그대로 두고 **Deploy**를 클릭합니다.
4. 배포 완료 후 나만의 커스텀 도메인 또는 `*.vercel.app` 주소로 즉시 사용 가능합니다!

## 🛠️ 로컬 실행 방법

별도의 복잡한 설치 없이 브라우저나 간단한 HTTP 서버로 즉시 실행할 수 있습니다.

```bash
# 저장소 복제
git clone https://github.com/udd43/Myplan.git
cd Myplan

# 로컬 서버 실행 (Python 예시)
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 열면 실행됩니다.
